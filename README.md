# irlib
irlib - potentially the most coprehensive interdisciplinary repo for physics and chemistry

irlib, IRlib, ir_lib? maybe irLib? you decide

Status - Beta Coming SOON (soon is not a promise ;] )

Why? 

Because why not. Also because I want to learn myself and teaching others or just digesting and processing information and building something with it is a great way to learn imo. 

How?

An indexed library of .md entries, a shit ton of tools like notepad, whiteboard and calculators. Graphing and scientific. 
Simulations, mapping conection between concepts, questions, explanations for those confused and a ton of cited sources if you want to explore source material yourself.

Then what?

Then ya'll can do anything with it. Sell it. Use it. Share it. Eat it? (Don't eat software, not a good idea. I would know). 

When?

Honestly, whenever I want to. I'm notoriously sporadic in how I make progress so...good luck actually seeing this thing done anytime soon.

But why still?

Well. Scattered sources, plain white pages of a book and boring lectures that suck the souls out of most students limit many learning styles and debilitate interest and self-motivation. This will (hopefully) provide the environment for different learning styles, different memorization techniques and workflows.
